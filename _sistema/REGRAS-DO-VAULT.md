# Regras operacionais do vault

> [!important] Fontes de verdade
> [Catálogo JSON](../catalogo/catalogo.json) mantém IDs e classificações; [Planejamento](../docs/PLANEJAMENTO.md) mantém marcos concluídos.

- Uma nota por ID de conceito (168 entradas, sem duplicatas).
- Valores `planejado` ou `rascunho` são distintos de `publicado`.
- Afirmar algo sobre uma experiência histórica exige país, data e fontes.
- Os MOCs conectam conceitos e volumes, mas não mudam a classificação canônica.
- Links Markdown relativos para compatibilidade com GitHub e Obsidian.
- Documentar autor, obra, edição e localização da fonte.
- Nenhum conteúdo de terceiros sem autorização.
- Não versionar `.obsidian/workspace.json` nem dados pessoais.
- Atualizar checklists e CHANGELOG a cada marco realmente concluído.
