# Dados estruturados

O arquivo [verbete-exemplo.json](verbete-exemplo.json) demonstra um **rascunho** com 15 dimensões, não uma publicação revisada.

Schemas: [catálogo](../schemas/catalogo.schema.json) e [verbete](../schemas/verbete.schema.json).

O ID deve ser canônico e igual ao do catálogo. As fontes devem ser verificadas; JSON válido não certifica correção histórica.
