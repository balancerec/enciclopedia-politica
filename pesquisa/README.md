# Acervo de pesquisa e fontes

Este diretório contém fontes identificadas, resumos metodológicos e fichamentos por verbete. A pesquisa não deve ser confundida com revisão humana ou publicação.

## Estrutura
- [fontes/liberalismo.json](fontes/liberalismo.json): registro bibliográfico por ID.
- [fichamentos/liberalismo.md](fichamentos/liberalismo.md): achados, limites e questões abertas.

## Procedimento
1. Confirmar título, autor, data, tipo e localização.
2. Separar fonte primária de análise acadêmica posterior.
3. Identificar trechos e seções usados para justificar afirmações.
4. Relacionar cada afirmação do verbete ao ID estável de fonte.
5. Registrar o que **não** foi lido ou verificado e não preencher com conjectura.
6. Não alterar status editorial para publicado sem processo de revisão.

## Observação
As datas de revisão e autores das fontes acadêmicas são verificadas nas próprias páginas referenciadas. A existência de um link não significa que a obra completa foi lida.
